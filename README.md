## 구현할 기능 목록

### 입력 처리
- [x] 사용자로부터 문자열 입력받기

### 구분자 처리
- [x] 기본 구분자(쉼표, 콜론) 처리
- [x] 커스텀 구분자 파싱 (`//`와 `\n` 사이의 문자)
- [x] 구분자를 기준으로 문자열 분리

### 숫자 추출 및 계산
- [x] 분리된 문자열에서 숫자 추출
- [x] 추출한 숫자들의 합 계산
- [x] 빈 문자열 입력 시 0 반환

### 예외 처리
- [x] 잘못된 입력에 대한 IllegalArgumentException 발생

### 출력
- [x] 계산 결과 출력
